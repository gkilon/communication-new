# Chrome Extension — MVP

## מה זה עושה
תוסף Chrome שרץ בתוך Gmail. מוסיף כפתור "בדיקת סגנון" ליד כל חלון כתיבת מייל.
לחיצה עליו פותחת פאנל שבו אפשר לבחור נמען (מתוך עמיתים בארגון שלך שמילאו את
השאלון) ולקבל משוב על הטיוטה — מול הסגנון שלך ושל הנמען. משתמש באותו backend
כמו האתר (`/api/gemini`, `/api/get-context`).

## לפני שמתקינים — שלב אחד חובה
פתח את `extension/config.js` ומלא את `FIREBASE_API_KEY` עם הערך של
`VITE_FIREBASE_API_KEY` (אותו ערך שכבר יש לך ב-Netifly Environment Variables).
זהו מפתח ציבורי (לא סוד) — הוא כבר חשוף בקוד של האתר עצמו.

אם כתובת האתר החיה השתנתה (למשל אחרי חיבור דומיין מותאם אישית), עדכן גם את
`SITE_URL` באותו קובץ.

## איך טוענים את התוסף בדפדפן (למצב פיתוח)
1. Chrome → `chrome://extensions`
2. הפעל "Developer mode" (מתג בפינה הימנית העליונה)
3. "Load unpacked" → בחר את התיקייה `extension/` מתוך הריפו
4. אמור להופיע אייקון חדש בסרגל הכלים

## איך בודקים
1. לחץ על אייקון התוסף → התחבר עם אותו מייל/סיסמה שיש לך באתר
2. פתח Gmail → התחל מייל חדש → אמור להופיע כפתור "✉️ בדיקת סגנון" מעל תיבת הכתיבה
3. כתוב כמה משפטים → לחץ על הכפתור → בחר נמען (אם יש) → "בדוק/י עכשיו"

## מגבלות של ה-MVP הזה (ידוע, לא באג)
- אין אייקון מותאם אישית לתוסף (Chrome משתמש בברירת מחדל)
- ההתחברות היא רק באימייל/סיסמה — אין עדיין כניסה עם Google בתוך התוסף
- הזיהוי של תיבת הכתיבה ב-Gmail מבוסס על מבנה ה-DOM הנוכחי של Gmail — אם גוגל
  ישנו את המבנה, ייתכן שהכפתור יפסיק להופיע ויידרש עדכון ב-`content.js`
- לא פורסם עדיין לחנות התוספים של Chrome — כרגע רק "Load unpacked" לבדיקות
